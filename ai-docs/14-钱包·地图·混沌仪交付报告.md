## 2. 各批落地要点（与规格的差异以代码为准）

- **W1 钱包**：`GoodData.wallet?`；`currency.*` 12 + `essence.*` 12 全部钱包化；
  `Player.loot` 走独立分支（无上限、永不 `lost`）；`InventorySlotDto.wallet?` +
  `WalletEntryDto` + `PlayerStateDto.wallet?`；`walletCount`/`costWallet`。
  *冲突*：既有测试把 `currency.chaos` 当普通可堆叠材料用（`player.test.ts` / `loot-lost.test.ts`），
  按代码改为 `potion` / `mucus`——这是**真实行为变更**，不是测试将就。
- **W2 删剧情**：10 个文件物理删除；`Requirement` 去 `stories`/`beforeStories`；`MapEntered`/`EnemyKilled`
  事件清零；`idle` 离线击杀事件链整体删除（`IdleService` 构造 4→3 参）；`story` cmd 段退役。
  *任务书清单遗漏但代码必须改*：`server/src/ionet/cmd.ts` 再导出 `STORY_CMD`、
  `ionet-transport` 的 `StoryApi`/`story-store` 等（不改则 build 直接失败）。
  去掉 `stories` 后 `town.street`/`town.valley` 变 `{}` 即解锁，原先断言它们锁定的用例/冒烟
  改钉 `silver.warrior`（W3 后改钉新图）。
- **W3 新地图**：`maps-world.ts`（`home` + `world.1..13`）；`MapData.boss?`；
  `mapListDtoOf` 改等级段排序；`CareerInfo.maxLevel` 默认 100；**生产代码 `peak` 零命中**；
  DB `peak_level` 列已 `DROP`（`init-db.mjs` 幂等）。
  *数据实测*：`nightmare.*` 只有 6 张（任务书「31」是旧秘境总数）；
  `chapter3.murloc.army` 存在但**没有 loots**。
- **W4 波次/BOSS**：`Born.reset()` + `EnemyBorn.wave`（随 `dumpState` 往返）；
  每 20 波守关 BOSS；`EnemyUnit.levelOverride`（普通地图等级 / 稀有 +1 / BOSS +2）；
  `Player.worldBossKilled` + `Requirement.bossKilled`（缺失 fail-closed）。
  *实现收敛*：只在 `mapData.level` 为有限数时覆写等级（缺 level 的图回落旧公式）；
  金样 state 哈希因新增 `wave` 字段重录，事件流哈希不变。
- **W5 钥石**：`keystone.t01..t16`（material + stack，**非钱包**）；`rules/keystone.ts`；
  `BattleWorld.rollKeystoneDrop`：仅地图 ≥85，`tier=clamp(level-84,1,16)`，
  单怪最多掉 **自身阶+1**，基础率 5%，`P(cap)=0.75` 否则 `1..cap-1` 均匀。**无词缀、无加工入口**。
- **W6a 删旧秘境**：`dungeon` 段（140）、`challengeQueue`/`dungeonRuns`/`dungeonCooldowns`、
  `dungeonTickets`/`countTicket`/`costTicket`、`endlessLevel`/`pendingMaps`、`nightmare.*`/
  `data/packages/nightmare.ts`、`DungeonState`/phases、`year2018.dungeon`、`dungeon-queue-smoke`、
  `dungeon → map` 白名单（`TRANSITIONAL_DEEP_IMPORTS` 现为空）。逻辑服 `dungeon` → `idle`。
  离线结算重写为「当前持久化地图（有怪才结算）→ VirtualClock 预算模拟 → 报告 → 落位置」。
  *对账*：删除 57 条用例（整文件 32 + 文件内 25），game-core 578→535、server 399→366 完全吻合。
- **W6b 混沌仪**：`chaos.t01..t16`（等级 84+T，`MapData.chaos?`，从 `map.list` 过滤）；
  解锁 = 13 张野外 BOSS 全清；钥石序列（≤16、可重复）+ 失败两分支（`normal` 中断回图 /
  `continue` 重试、连败 3 次跳下一把）；`chaos-ops.ts` 纯状态机（在线/离线共用）；
  battle `chaosOutcome` → `ChaosRunEnded` 事件 → `ChaosLogicService` 用
  `BATTLE_COMMAND.enterMap(..., {allowChaos:true})` 推进；`chaos` 段 = 140。
